SHARPMANAGER BASIC PC-1403 — WINDOWS V5.2 (CONTINUOUS STREAMING)
English translation of the delivery notes, 6 October 2026.

This Windows version retains BASIC conversion and CSAVE reception from V5,
then adds the changes validated in SharpManager macOS V5.2.

BUILDING FROM THE GITHUB SOURCES
The repository contains sources, not a Windows installer. Install the .NET 10
SDK inside Windows (x64 on Intel/AMD; Arm64 on Windows ARM / Apple Silicon).
Download: https://dotnet.microsoft.com/en-us/download/dotnet/10.0
Close all terminal windows and reopen PowerShell. Check dotnet --version,
then run .\BuildWindowsBasic.bat from this directory. Launch
publish-windows\SharpManagerBasicPc1403.exe after a successful build.
The script targets win-x64. Windows ARM also needs x64 emulation and the
.NET 10 Desktop Runtime x64 to run that build. See README.md for details.

INSTALLATION OF AN ALREADY COMPILED APPLICATION
1. Extract the entire archive into a NEW Windows x64 directory.
2. Run SharpManagerBasicPc1403.exe. Keep PocketTools and all DLLs alongside
   the executable.
3. If Windows requests it, install the .NET 10 Desktop x64 runtime.
4. Select the COM port of the FTDI cable, then click Connect.

The title should display “Windows V5.2 flux continu”. Preferences remain in
%LOCALAPPDATA%\SharpManagerBasicPc1403\V5\settings.json, as in V5.

TRANSFER WITH THE “FLUX CONTINU V5 - GARDE 64” FIRMWARE
- Envoyer BASIC (Send BASIC) converts a numbered .bas file to PC-1403 TAP
  before requesting CLOAD on the Sharp. Sending an existing TAP is still
  available.
- The application automatically detects “flux continu V5” in the Pro Mini
  response. It then accepts up to 32767 bytes, waits up to 20 seconds for each
  ACK and reports progress every eight blocks.
- After the final ACK, it waits for ETX, which confirms the end of the cassette
  signal. An ACK alone means the data is in the Arduino buffer.
- An error reports the block number and byte range, then closes the link.
  Click Connect again. If three SYN attempts receive no reply, the application
  attempts a reset through RTS/DTR, waits for the bootloader and resynchronizes.
  The RTS-to-DTR/reset connection must be present for this recovery to work.
- With older firmware, block waiting retains the V5 behavior.

FIRMWARE
The working “garde 64” firmware already installed on the Pro Mini does not
need to be uploaded again. The Upload Firmware window offers two
“flux continu V5 garde 64” profiles: 57600 (old bootloader) and 115200
(new bootloader). Choose only the bootloader speed that works with your
Pro Mini. Firmware/SharpStreamSafe.hex and its Arduino source code are also
included. Firmware upload is never automatic.

RECEIVE / CSAVE
The receive menu offers readable BASIC (.bas) or a raw cassette file (.tap).
If BASIC decoding fails, the TAP file can still be saved without repeating
reception.

SUPPLIED TESTS AND LIMITATIONS
The Exemples directory contains a compact Queen's Quest adaptation for the
standard PC-1403, rather than the full PC-1403H game.
Windows x64 build and simulation covered a 5717-byte transfer over 90 blocks,
ACKs, final ETX, reconnection, CSAVE reception and older firmware. The new
Windows application has not yet been tested with the physical FTDI link or
on the Sharp. The simulator does not verify the electrical waveform.
