QUEEN'S QUEST - adaptation for the standard Sharp PC-1403 (8 KB)
English translation of the delivery notes, 6 October 2026.

This adaptation of Patrick Zumstein's BASIC game is a compact version for
the standard PC-1403. The original PC-1403H game remains unchanged.

Files:
  QUEENS_QUEST_PC1403.bas: editable BASIC source
  QUEENS_QUEST_PC1403.tap: file to send using SharpManager

To test it, load the .tap file using SharpManager, then enter RUN on the Sharp.
Choose difficulty 1, 2 or 3. Commands accept their first two letters:
NO, SO, EA, WE (movement), LO (look around), TA (take an item),
FI (fight), US (drink a potion), ST (status), MA (map).

The map is 7 x 7 cells instead of 14 x 14. Detailed descriptions, item tables
and the original potion categories have been simplified. The objective is
still to reach cell Q and defeat the guard to free the queen.
On the map, @ marks the player's position and . marks an unknown cell.

Conversion to a PC-1403 BASIC image and then TAP was checked by decoding the
result back to BASIC. Encoded BASIC image size: 2299 bytes. Execution and
available memory still need to be checked on a real PC-1403.
If the Sharp displays an error, record both the error number AND the line
number, and indicate whether it occurs during CLOAD, when RUN starts, or
after a command. The MEM command on the Sharp reports the remaining free
memory.
