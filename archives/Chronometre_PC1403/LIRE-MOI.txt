CHRONOMETRE BASIC POUR SHARP PC-1403

Fichiers : CHRONO.tap (transfert), CHRONO.bas (source modifiable).

INSTALLATION
1. Conserver la sauvegarde du programme actuel : CLOAD le remplace.
2. SharpManager connecte au port FTDI (COM5 dans votre montage).
3. Sharp en RUN : saisir CLOAD puis ENTER.
4. Windows : File > Send Tape File... et choisir CHRONO.tap.
5. Attendre la fin du chargement puis saisir RUN, ENTER.
6. ENTER demarre le compteur a 00:00:00.
7. BREAK interrompt. RUN puis ENTER, ENTER recommence a zero.

PRECISION
Cette version BASIC est demonstrative : WAIT 59 fait attendre PRINT
pendant environ une seconde, a laquelle s'ajoute le temps des calculs.
Elle retarde donc par rapport a un chronometre de reference.
La precision et le fonctionnement n'ont pas ete testes sur une machine physique.
Pour calibrer : en PRO, remplacer la ligne 30 par
30 H=0:M=0:S=0:W=50
puis ajuster W en comparant avec un chronometre (diminuer W si le Sharp
retarde, augmenter W s'il avance). La valeur 50 est un essai, pas une
valeur calibree. Le passage de minute ajoute aussi un peu de temps.

RECONSTRUIRE APRES MODIFICATION
Avec Pocket Tools (bas2img.exe et bin2wav.exe) :
bas2img.exe --pc=1403 CHRONO.bas CHRONO.img
bin2wav.exe --pc=1403 --tap --name=CHRONO CHRONO.img CHRONO.tap

La conversion TAP -> BASIC a ete verifiee avec Pocket Tools.
