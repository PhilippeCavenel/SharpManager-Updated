BASIC STOPWATCH FOR SHARP PC-1403
English translation of the delivery notes, 6 October 2026.

Files: CHRONO.tap (transfer file), CHRONO.bas (editable source).

INSTALLATION
1. Back up the current program: CLOAD replaces it.
2. Connect SharpManager to the FTDI port (COM5 in this setup).
3. On the Sharp in RUN mode, enter CLOAD and press ENTER.
4. On Windows, select File > Send Tape File... and choose CHRONO.tap.
5. Wait for loading to finish, then enter RUN and press ENTER.
6. ENTER starts the counter at 00:00:00.
7. BREAK stops it. Enter RUN, then press ENTER twice to restart from zero.

ACCURACY
This BASIC version is a demonstration: WAIT 59 makes PRINT wait for
approximately one second, in addition to the time required for calculations.
It therefore runs slow compared with a reference stopwatch.
Accuracy and operation have not been tested on a physical machine.
To calibrate it, switch to PRO mode and replace line 30 with:
30 H=0:M=0:S=0:W=50
Then adjust W against a reference stopwatch: decrease W if the Sharp runs
slow, or increase W if it runs fast. The value 50 is a trial value, not a
calibrated setting. Each minute rollover also adds a little processing time.

REBUILD AFTER EDITING
Using Pocket Tools (bas2img.exe and bin2wav.exe):
bas2img.exe --pc=1403 CHRONO.bas CHRONO.img
bin2wav.exe --pc=1403 --tap --name=CHRONO CHRONO.img CHRONO.tap

TAP-to-BASIC conversion was checked using Pocket Tools.
