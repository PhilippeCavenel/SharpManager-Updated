64-BYTE BOUNDARY TEST — SHARP PC-1403
English translation of the delivery notes, 6 October 2026.

Both programs display TEST OK, then stop. Only the length of the REM comment
differs. The cassette name and header are identical.

1. Use the same SharpManager version for both tests.
2. First test: load 64_octets/TEST.bas using Envoyer BASIC (Send BASIC).
3. Second test: load 65_octets/TEST.bas using Envoyer BASIC (Send BASIC).
4. For each file, record whether CLOAD finishes or displays ERROR 8.
5. If necessary, compare with the supplied TEST.tap files using Send Tape File.

Each load replaces the program currently on the Sharp.
If the first test fails, press ON/BREAK before restarting CLOAD.
The .tap files were created using the same Pocket Tools as the converter.
The 64-byte test uses one serial block; the 65-byte test uses two.
A success/failure difference at this boundary would point to an inter-block
transfer problem, but would not yet prove its exact cause.
These physical transfers still need to be tested on your setup.
