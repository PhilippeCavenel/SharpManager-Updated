# Queen's Quest

**Queen's Quest was published by Patrick Zumstein on the Facebook page
“80's Sharp pocket computers” and remains his property.**

The original BASIC source identifies Patrick Zumstein and September 2026.
The Facebook publication context was supplied by Philippe Cavenel. This
archive also includes French translations, compact and 8K adaptations, and
the associated TAP files. These versions remain adaptations of Patrick
Zumstein's program; translation or conversion does not transfer ownership.

The latest corrected French 8K source is
[`Queens_Quest_PC1403_8K_FR_corrige.bas`](Queens_Quest_PC1403_8K_FR_corrige.bas).
The English 8K source and TAP are in [`8k-anglais`](8k-anglais/).
The original source and earlier variants are retained for provenance.
